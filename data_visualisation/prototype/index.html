SG-NEx m6A Explorer

Look up a gene and see, run by run, how many reads cover each candidate m6A site and what score the model gives it. Data from the Singapore Nanopore Expression Project: 23 direct RNA runs from 7 cell lines.

Placeholder scores. Every m6A score on this page is simulated so the layout can be tested before the team's predictions exist. Runs, read counts and gene names are real SG-NEx data. Do not quote any score, comparison or agreement figure from this version.

    How to read a score

    • A score is the model's confidence that a site is modified in one run. It is not the fraction of RNA molecules that carry m6A.
    • A site with no reads in a run is unmeasured. It is not evidence that the site is unmodified.
    • Runs of the same replicate are repeat sequencing of one sample. Only different replicates count as independent biological repeats.
    • All scores are predictions. None has been confirmed by an independent experiment in these cell lines.
    • The model learned from Hct116 labels. Scores in other cell lines assume the same signal patterns carry over.

      Replacing the placeholder with real predictions

      Teammates send one folder: manifest.csv, MODEL_INFO.md and one predictions/<run_id>.csv per run with the columns transcript_id,transcript_position,score. Then:

      python scripts/validate_task2_inputs.py --inputs task2_inputs --public public_data
python scripts/build_site_data.py --public public_data --predictions task2_inputs --out site/data
python scripts/package_site.py

      The validator checks every file against the public read counts for its run and stops on any mismatch. The page itself does not change; the warning banners disappear once the model version is no longer a placeholder.
