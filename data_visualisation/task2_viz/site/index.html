    Comparing cell lines

    Scores are compared only on sites measured in every cell line, so a missing site is never read as an unmodified one. A line's score is the mean over its replicates, each replicate being the mean of its runs with enough reads.

    Sites that can be compared across all seven cell lines

    Annotated-gene sites measured in every line, by read threshold and by how many replicates per line must measure the site.

    Stricter rules leave fewer sites but make each comparison rest on more independent samples. These counts come from measured reads only.

    How to read this page

    • A site with no reads in a run is unmeasured. It is not evidence that the site is unmodified.
    • Read counts say how well a site was measured. They are not a direct measure of how much RNA the cell makes.
    • Runs of the same replicate are repeat sequencing of one sample. Only different replicates count as independent biological repeats.
    • A score, once shown, is the model's confidence that a site is modified. It is not the fraction of RNA molecules carrying m6A, and no score has been confirmed by an independent experiment in these cell lines.
    • Replicates were sequenced on different dates, devices and basecaller versions. Differences between them can be technical.

    Data issues and checks

      Adding the team's predictions

      The prediction hand-off uses the team's nine-column manifest.csv (run_id, cell_line, biological_replicate, sequencing_run, prediction_file, coverage_file, min_reads, reference_version, model_version), a completed MODEL_INFO.md, and one CSV per run with the columns transcript_id,transcript_position,score. Then:

      python scripts/validate_task2_inputs.py --inputs task2_inputs --public public_data
python scripts/build_site_data.py --public public_data --sample-metadata team_inputs/member4_2026-10-19/sample_manifest.csv --predictions task2_inputs --score-status exploratory --out site/data
python scripts/package_site.py

      The validator checks every file against the public read counts for its run and refuses a manifest whose model is still pending. Use --score-status final only once the team has selected the model.
